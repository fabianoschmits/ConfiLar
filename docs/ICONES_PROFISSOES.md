1. **Página de Busca** (`/buscar`)

   - Cards de profissionais com badges de serviços
   - Popover de serviços oferecidos

2. **Perfil de Profissionais** (`/perfil/[id]`)
   - Aba "Serviços" com lista de serviços oferecidos

3. **Formulário de Dados Profissionais** (`/editarperfil/dados-profissionais`)
   - Seleção múltipla de serviços oferecidos

4. **Formulário de Criação de Posts** (`/feed`)
   - Seleção de categoria de serviço para o post

5. **Formulário de Anúncios Classificados** (`/classificados`)
   - Seleção de tipo de serviço para o anúncio

6. **Onboarding** (`/onboarding`)
   - Seleção de serviços durante cadastro

7. **Timeline Posts** (`/feed`)
   - Badge de categoria de serviço nos posts

## 🎨 Especificações para Ícones Personalizados

### Formato Recomendado
- **SVG** (preferencial) - Escalável e leve
- **PNG** (alternativa) - 24x24px, 32x32px, 48x48px (múltiplas resoluções)

### Estilo Sugerido
- **Linha/Outline** - Estilo consistente com lucide-react
- **Cores:** Monocromático (preto/branco) ou com suporte a tema (claro/escuro)
- **Tamanho padrão:** 24x24px (1rem)
- **Stroke width:** 1.5-2px

### Estrutura de Pastas Sugerida
```
public/
  imagens/
    icones/
      profissoes/
        construcao-reforma/
          construction.svg
          masonry.svg
          electrical.svg
          ...
        limpeza-higiene/
          cleaning.svg
          housekeeping.svg
          ...
        ...
```

## 🔄 Plano de Migração

### Fase 1: Preparação
1. Criar estrutura de pastas
2. Definir padrão de nomenclatura
3. Criar componente `ServiceIcon` com fallback para emojis

### Fase 2: Criação de Ícones
1. Priorizar categorias mais usadas
2. Criar ícones em lote por categoria
3. Testar em diferentes tamanhos e temas

### Fase 3: Implementação
1. Atualizar `src/data/services.ts` gradualmente
2. Manter compatibilidade com emojis durante transição
3. Testar em todas as páginas que usam serviços

### Fase 4: Finalização
1. Remover fallback de emojis
2. Otimizar ícones (SVG minificado)
3. Documentar novos ícones

## 📝 Notas

- Alguns emojis são repetidos (ex: ✂️ usado em Cabeleireiro e Tosador)
- Alguns serviços têm ícones similares (ex: 🧱 usado em Pedreiro e Pisos)
- Considerar criar ícones únicos e distintos para cada serviço
- Manter consistência visual entre ícones da mesma categoria
