## 📋 Checklist Simplificado

### **Antes de Usar o PWABuilder**

- [ ] ✅ Site em produção com HTTPS (ex: https://confilar.com.br)
- [ ] ✅ Manifest.json acessível em `/manifest.json`
- [ ] ✅ Service Worker funcionando
- [ ] ✅ Testar PWA no Chrome (DevTools → Lighthouse → PWA)
- [ ] 📸 Criar 2-4 screenshots bonitas do app (1080x1920px)
- [ ] 🎨 Ícone final 512x512px (para Google Play)

### **No PWABuilder**

1. [ ] Acessar https://www.pwabuilder.com
2. [ ] Inserir URL: `https://seusite.com.br`
3. [ ] Clicar em "Start" e aguardar análise
4. [ ] Verificar score (deve ser > 130 pontos)
5. [ ] Clicar em "Package for Stores"

### **Para Android (Google Play)**

- [ ] Selecionar "Android"
- [ ] Configurar:
  - **Package ID**: `com.confilar.app`
  - **App Name**: `ConfiLar`
  - **Version**: `1.0.0`
  - **Theme Color**: `#000000`
- [ ] Deixar PWABuilder gerar keystore (ou usar sua própria)
- [ ] Clicar em "Build"
- [ ] Download do arquivo `.aab`

### **Publicar na Google Play**

- [ ] Criar conta Google Play Developer ($25 USD uma vez)
- [ ] Acessar https://play.google.com/console
- [ ] Criar novo app
- [ ] Upload do arquivo `.aab`
- [ ] Adicionar:
  - Descrição
  - Screenshots (mínimo 2)
  - Ícone 512x512
  - Imagem de destaque
  - Política de privacidade (URL)
- [ ] Enviar para revisão

### **Para iOS (Opcional)**

- [ ] Ter conta Apple Developer ($99/ano)
- [ ] Ter Mac com Xcode
- [ ] Baixar pacote iOS do PWABuilder
- [ ] Abrir no Xcode
- [ ] Compilar e enviar para App Store
