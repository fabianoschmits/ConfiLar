# 🏠 ConfiLar - Plataforma de Confiança Profissional

> **Sistema completo de conexão entre profissionais e clientes com sistema de confiança, avaliações, feed social em tempo real e economia de pontos.**

## 🎯 Visão Geral

O **ConfiLar** é uma plataforma inovadora que conecta profissionais qualificados com clientes, oferecendo um ecossistema completo de confiança baseado em avaliações, recomendações, interações sociais em tempo real e um sistema de economia interna com pontos.

### 🎪 Principais Diferenciais

- **🔒 Sistema de Confiança**: Avaliações, recomendações e histórico profissional
- **📱 Feed Social**: Interações em tempo real com posts automáticos
- **🎨 Avatars Inteligentes**: Geração automática baseada no nome do usuário
- **💬 Chat Integrado**: Sistema de mensagens flutuante
- **📊 Analytics**: Estatísticas e métricas de performance
- **🔍 Busca Avançada**: Filtros por localização, serviços e disponibilidade
- **💰 Sistema de Pontos**: Economia interna com gamificação
- **🔔 Notificações Inteligentes**: Sistema completo com sons e push notifications
- **📱 PWA Completo**: App instalável com funcionalidades offline

## ✨ Funcionalidades Implementadas

### 👥 Para Usuários (Clientes e Profissionais)

#### 🔐 Sistema de Autenticação
- **Cadastro Simplificado**: Formulário único para clientes e profissionais
- **Verificação por Email**: Confirmação de conta obrigatória
- **Recuperação de Senha**: Sistema seguro de reset
- **Onboarding Inteligente**: Completar perfil com avatar automático
- **Reautenticação Segura**: Sistema OTP para ações sensíveis
- **Troca de Email**: Processo seguro com verificação

#### 👤 Perfil Completo
- **Informações Pessoais**: Nome, foto, localização, contato
- **Avatar Inteligente**: Geração automática baseada no nome
- **Sistema de Favoritos**: Salvar profissionais de interesse
- **Histórico de Atividades**: Acompanhar interações e conquistas
- **Sistema de Badges**: Bronze, Silver, Gold com progressão
- **Verificação de Perfil**: Sistema de validação de documentos

#### 💬 Comunicação
- **Chat Flutuante**: Sistema de mensagens em todas as páginas
- **Notificações em Tempo Real**: Alertas de mensagens e atualizações
- **Histórico de Conversas**: Acompanhar todas as interações
- **Status de Leitura**: Indicadores de mensagens lidas/não lidas
- **Sistema de Menções**: @mencionar usuários em posts e comentários

## 🚀 Tecnologias Utilizadas

### Frontend
- **Next.js 14**: Framework React com App Router
- **TypeScript**: Tipagem estática para maior confiabilidade
- **Tailwind CSS**: Estilização moderna e responsiva
- **React Query**: Gerenciamento de estado e cache
- **Zustand**: Gerenciamento de estado global
- **React Hook Form**: Formulários performáticos
- **Zod**: Validação de schemas

### Backend
- **Supabase**: Backend-as-a-Service completo
- **PostgreSQL**: Banco de dados relacional
- **Row Level Security**: Segurança granular
- **Realtime**: WebSockets para tempo real
- **Edge Functions**: Serverless functions

### PWA e Mobile
- **Service Worker**: Cache e funcionalidades offline
- **Web App Manifest**: Instalação como app nativo
- **Push Notifications**: Notificações nativas
- **Vibration API**: Feedback tátil

### Ferramentas de Desenvolvimento
- **ESLint**: Linting de código
- **Prettier**: Formatação automática
- **Jest**: Testes unitários
- **Playwright**: Testes E2E
- **GitHub Actions**: CI/CD

## 🚀 Como Executar

### Pré-requisitos
- Node.js 18+
- npm ou yarn
- Conta no Supabase

### Instalação
```bash
# Clone o repositório
git clone https://github.com/seu-usuario/confilar.git

# Instale as dependências
npm install

# Configure as variáveis de ambiente
cp .env.example .env.local

# Execute o projeto
npm run dev
```

### Configuração do Supabase
1. Crie um projeto no Supabase
2. Configure as variáveis de ambiente
3. Execute os scripts SQL na pasta `scripts/`
4. Configure as políticas RLS
